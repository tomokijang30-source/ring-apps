# ring-apps
Public legal and support pages for apps by Ring (링), a sole proprietorship in the Republic of Korea.
- Shift Pay: https://tomokijang30-source.github.io/ring-apps/shiftpay/
- Kakepo: https://tomokijang30-source.github.io/ring-apps/kakepo/ (`node _src/gen_kakepo.mjs`)
Pages are generated by `node _src/gen.mjs` (plain HTML, no Jekyll).
